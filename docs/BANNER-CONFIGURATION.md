# Banner Image Configuration Guide

This guide explains how banner images are configured and used across the prediction contests website.

## Overview

The website uses a sport-specific banner scheme that automatically applies different images to different page types (leaderboard, predictions, rules, blog posts).

## Configuration Structure

Banner images are configured in the contest config JSON files located in `data/scripts/`:

- `contest_config.json` - T20/Cricket contests (active contest)
- `contest_config_nfl.json` - NFL contests

### Banner Configuration Format

```json
{
  "background_images": {
    "leaderboard": "/img/nfl/bg_nfl1.webp",
    "predictions": "/img/nfl/2025_NFL.png",
    "rules": "/img/nfl/bg_nfl2.jpg",
    "blog_posts": [
      "/img/nfl/bg_nfl.webp",
      "/img/nfl/bg_nfl1.webp",
      "/img/nfl/bg_nfl2.jpg"
    ]
  }
}
```

## Page Types

### 1. Leaderboard
- **Purpose**: Main scoring page showing live standings
- **Image style**: Action-packed, dramatic images
- **Usage**: Auto-generated by scoring script

### 2. Predictions
- **Purpose**: Shows all submitted predictions
- **Image style**: Team logos, branding images
- **Usage**: Manual page creation, updated via scoring script reference

### 3. Rules
- **Purpose**: Contest rules and scoring system
- **Image style**: Stadium, venue images
- **Usage**: Manual page creation

### 4. Blog Posts
- **Purpose**: Contest updates and announcements
- **Image style**: Rotating through multiple images
- **Usage**: Auto-generated by scoring script with `--generate-blog` flag
- **Behavior**: Randomly selects one image from the `blog_posts` array

## How It Works

### Automated Pages (Generated by Script)

The scoring script (`score_active_contest_predictions.py`) automatically applies banners to:

1. **Main Leaderboard** - Uses `leaderboard` banner
2. **Group Leaderboards** - Uses `leaderboard` banner
3. **Blog Posts** - Randomly selects from `blog_posts` array

Run the script with:
```bash
cd data/scripts
uv run python score_active_contest_predictions.py --generate-blog --config contest_config_nfl.json
```

### Manual Pages (Static Content)

For manually created pages like predictions and rules, update the front matter directly:

```yaml
---
layout: page
title: "Predictions - NFL 2025-26"
description: "All submitted predictions"
background: '/img/nfl/2025_NFL.png'
permalink: "/nfl-2025/predictions"
---
```

## Adding New Banners

### 1. Add Image Files

Place banner images in the appropriate directory:
- **NFL banners**: `/img/nfl/`
- **Cricket/T20/ICC banners**: `/img/cricket/`
- **Generic banners**: `/img/posts/`

This organizational structure keeps sport-specific images separate and makes it easier to manage multiple contests.

### 2. Update Config File

Edit the contest config JSON:

```json
"background_images": {
  "blog_posts": [
    "/img/nfl/bg_nfl.webp",
    "/img/nfl/bg_nfl_new.jpg",  // Add new banner here
    "/img/nfl/bg_nfl2.jpg"
  ]
}
```

### 3. Regenerate Files

Run the scoring script to apply changes:
```bash
cd data/scripts
uv run python score_active_contest_predictions.py --config contest_config_nfl.json
```

## Banner Selection Logic

The `get_background_image()` function in the scoring script:

1. **Blog posts**: Randomly selects from `blog_posts` array using Python's `random.choice()`
2. **Other pages**: Returns the specific banner for that page type
3. **Fallback**: Uses `/img/bg-post.jpg` if configuration is missing

## Recommended Banner Sizes

- **Width**: 1920px (for full-width backgrounds)
- **Height**: 600-1200px (aspect ratio 16:9 or wider)
- **Format**: WebP (best compression) or JPG/PNG
- **File size**: Keep under 500KB for fast loading

## Troubleshooting

### Gray Banner Appearing
**Problem**: Page shows default gray banner
**Solution**: Check the page's front matter has correct `background:` path

### Same Banner on All Pages
**Problem**: All pages use the same image
**Solution**: Verify `background_images` object exists in config with all page types

### Blog Posts Not Rotating
**Problem**: Blog posts always use the same banner
**Solution**: Ensure `blog_posts` is an array with multiple images

## Image Organization

All banner images are organized by sport:

- **NFL**: `/img/nfl/` - Contains all NFL-related banners
- **Cricket**: `/img/cricket/` - Contains all cricket, T20, and ICC-related banners
- **Generic**: `/img/posts/` - General-purpose images for non-sport-specific content

This structure makes it easy to:
- Find sport-specific images quickly
- Avoid filename conflicts between sports
- Manage and update banners systematically
- Add new sports (e.g., `/img/fifa/` for soccer)
